# 배열에서 최댓값 * 최솟값 구하기
## 문제
정수 배열 numbers가 매개변수로 주어집니다. numbers의 원소 중 두 개를 곱해 만들 수 있는 최댓값을 return하도록 solution 함수를 완성해주세요.

## 알고리즘
1. 먼저 새롭게 최댓값과 다음 최댓값을 넣을 변수 2개를 생성한다.
2. 제공된 배열값(x)을 배열 길이 만큼 계속해서 반복한다
3. 만약 x값이 최댓값보다 크다면, 최댓값은 다음 최댓값 배열에 넣고 최댓값은 x로 갱신한다.
4. 만약 다음 x값이 기존의 최댓값과 같다면 기존 최댓값을 다음 최댓값 변수에 저장하고 같은 값이라도 최댓값도 새로운 값을 대입한다.
5. 만약 다음 값이 기존의 최댓값보다 작다면 다음 else if 문으로 가고, 여기서 기존의 다음 최댓값보다 새로운 값이 더 크다면 기존의 다음 최댓값을 새로운 값으로 바꾼다.
6. 여기서 새로운 값이 기존의 다음 최댓값보다 작다면 else if문을 탈출한다.
