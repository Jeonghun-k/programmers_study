# 문자열 곱하기 - 프로그래머스

## 제출한 코드
```python
def solution(my_string, k):
    for i in range(k):
        a = my_string*k
    answer = ''.join(a)
    return answer
```
## 설명
이따구로 이상하게 했다.

이렇게 했을 떄 정답처리는 되던데 뭔가 회의감이 들었었다.

코드 좀 생각 해보니 반복문 안에 i가 없으며 
굳이 join을 사용할 필요도 없는것같다
---

## 코드 재작성
```python
def solution(my_string, k):
    answer =  my_string * k
    return answer
```

이렇게만 해도 충분히 문자열을 반복해서 출력 할 수있다 그래서 이게 맞는듯
