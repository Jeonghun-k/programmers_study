# 더 크게 합치기 - 프로그래머스

## 코드
```python
def solution(a, b):
    x = str(a) + str(b)
    y = str(b) + str(a)
    if int(x > y):
        answer = int(x)
    else:
        answer = int(y)
    return answer
```

입력받은 정수를 정수의 합이 아닌 보이는 그대로 붙이려면 어떻게 해야되는지 고민을 해봤다

결과는 문자로 변환 후 문자를 더하게되면 문자 그대로 합쳐진다는 점을 이용하기로 했다
그래서 `x`에는 문자 `a+b` / `y`에는 문자 `b+a`를 각각 담아두었다

이후 조건문을 실행 할 땐 문자를 정수로 변환시켜 비교를 하고 
해당 값을 `answer`에도 정수로 변환시켜 담았다.
