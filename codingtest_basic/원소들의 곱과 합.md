# 원소들의 곱과 합 - 프로그래머스

## 문제
```
정수가 담긴 리스트 num_list가 주어질 때, 모든 원소들의 곱이 모든 원소들의 합의 제곱보다 작으면 1을 크면 0을 return하도록 solution 함수를 완성해주세요.
```

## 코드
```python
def solution(num_list):
    sum1 = 1
    sum2 = 0
    for i in num_list:
        sum1 *= i
    
    for j in num_list:
        sum2 += j
    
    if(sum1 < (sum2**2)):
        answer = 1
    else:
        answer = 0
    return answer
```

## 설명

1. 문제에서 모든 원소들의 곱과, 모든 원소들의 합의 제곱을 요구하였다. 그래서 곱이 담길 변수를 0으로 하였을 때 첫번쨰 곱하기 시 0이 되어버리므로 1로 선언을 한다
2. 합의 제곱을 담을 변수는 먼저 합을 구해야되기때문에 변수의 초깃값은 0이어도 상관 없어서 0으로 선언함.
3. 리스트의 크기만큼 반복문을 돌리면서 모든 원소들을 곱한 값을 담음
4. 리스트의 크기만큼 반복문을 돌리면서 모든 원소들의 합을 담음
5. 조건문을 통해 모든 원소들의 곱한 값과 모든 원소들의 합의 제곱값을 비교하여 1,0을 answer변수에 담음
