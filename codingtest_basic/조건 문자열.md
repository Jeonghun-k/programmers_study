# 조건 문자열 - 프로그래머스

*문제*
```
문자열에 따라 다음과 같이 두 수의 크기를 비교하려고 합니다.

두 수가 n과 m이라면
">", "=" : n >= m
"<", "=" : n <= m
">", "!" : n > m
"<", "!" : n < m
두 문자열 ineq와 eq가 주어집니다.
ineq는 "<"와 ">"중 하나고, eq는 "="와 "!"중 하나입니다.
그리고 두 정수 n과 m이 주어질 때, n과 m이
ineq와 eq의 조건에 맞으면 1을 아니면 0을 return하도록
solution 함수를 완성해주세요.
```

***
*코드*
```python
def solution(ineq, eq, n, m):
    if(ineq == ">"):
        if(eq == "="):
            if n >= m:
                answer = 1
            else:
                answer = 0
        elif(eq == "!"):
            if n > m:
                answer = 1
            else:
                answer = 0
    elif(ineq == "<"):
        if(eq == "="):
            if n <= m:
                answer = 1
            else:
                answer = 0
        elif(eq == "!"):
            if n < m:
                answer = 1
            else:
                answer = 0
    else:
        answer = 0
    return answer
```
---
*설명*  
<,>,=,!는 문자로 입력이 된다

그래서 조건문으로 `ineq = "<"` 이런식으로 문자일 경우,  
실제 계산식은 문자를 사용하는게 아닌 비교연산자를 그대로 입력하여 사용하였다.

그래서 제일 큰 기준으로 ineq를 선택했다.  
`ineq`가 `<`일 때 `eq`의 `=`과 `!`를  
`ineq`가 `>`일 때 `eq`의 `=`과 `!`이렇게 두개를 조건으로 두었다

여기서 주의 해야할 점이 `<!`, `>!`이런 비교연산자는 없다.  
그래서 뜻을 풀이 해보면 `n보다 m이 작지 않다`, `n보다 m이 크지 않다`가 된다.  
이말은 즉 `n이 m보다 크다`, `n이 m보다 작다`가 된다.  
그래서 이에 맞게 부등호를 수정해서 조건문을 만들었다.
