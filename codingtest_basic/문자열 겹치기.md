# 문자열 겹치기 - 프로그래머스

## 내가 제출한 답
```python
def solution(str1, str2):
    L1 = list(str1)
    L2 = list(str2)
    L3 = []
    for i in range(0, len(L1)):
        L3.append(L1[i])
        L3.append(L2[i])
    answer = ''.join(L3)
    return answer
```
문자열 겹쳐쓰기처럼 입력받은 문자를 리스트로 변경시킨다.
결과를 담을 빈 리스트를 추가한다

반복문을 이용해서 0부터 문자열 담은 리스트의 길이만큼 반복한다
L3리스트에 해당하는 인덱스의 값을 append함수를 사용해서 추가한다.

추가가 완료된 리스트를 answer에 연결시킨다.

---
## `오답노트`
처음에는 add를 사용해서 추가하려고했다.
하지만 오류가 발생해서 이유를 찾아보니 add는 파이썬에서 집합에서 사용하는 함수이고
내가 짠 코드는 리스트를 사용하니 append를 사용해야 리스트의 요소가 추가된다는 것을 알게되었다.
그리하여 append로 재작성하니 에러 없이 정상작동이 되었다.

| 함수 | 용도
|:---:|:---:|
|`.add` | 집합(set)
|`.append` | 리스트(list)
