# 주사위 게임 2 - 프로그래머스

## 문제
```
1부터 6까지 숫자가 적힌 주사위가 세 개 있습니다. 세 주사위를 굴렸을 때 나온 숫자를 각각 a, b, c라고 했을 때 얻는 점수는 다음과 같습니다.

세 숫자가 모두 다르다면 a + b + c 점을 얻습니다.
세 숫자 중 어느 두 숫자는 같고 나머지 다른 숫자는 다르다면 (a + b + c) × (a2 + b2 + c2 )점을 얻습니다.
세 숫자가 모두 같다면 (a + b + c) × (a2 + b2 + c2 ) × (a3 + b3 + c3 )점을 얻습니다.
세 정수 a, b, c가 매개변수로 주어질 때, 얻는 점수를 return 하는 solution 함수를 작성해 주세요.
```

## 코드
```python
def solution(a, b, c):
    if(a != b and b != c and a != c):
        answer = a + b + c
    elif(a == b and b != c and c != a):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    elif(b == c and b != a and c != a):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    elif(c == a and a != b and c != b):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    else:
        answer = (a + b + c) * (a**2 + b**2 + c**2) * (a**3 + b**3 + c**3)
    return answer
```

### 설명

1. 조건문을 통해, 3개의 수가 모두 다 다른 경우를 만든다
2. elif를 통해 두가지 수만 같은 경우를 만드는데 이 때 a = b가 같으면 a,c / b, c는 달라야된다. 이런 경우가 3가지가 나오기 때문에 3가지 모두를 선언해준다
3. 마지막으로 모두 같은 경우를 만들어둔다.


## 틀린 점

### 틀린 코드

```python
def solution(a, b, c):
    if(a != b & b != c & a != c):
        answer = a + b + c
    elif(a == b & b != c & c != a):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    elif(b == c & b != a & c != a):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    elif(c == a & a != b & c != a):
        answer = (a + b + c) * (a**2 + b**2 + c**2)
    else:
        answer = (a + b + c) * (a**2 + b**2 + c**2) * (a**3 + b**3 + c**3)
    answer = 0 
    return answer
```

### 틀린점

1. 전체적인 메커니즘은 동일하다
2. and가 아닌 &를 사용하였다.
   - and는 논리연산자이고, &는 비트연산자이다.
   - 여기서는 비트 비교가 아닌 논리적으로 a,b,c의 다름을 판단하는것이므로 논리연산자를 사용해야된다
   - 그래서 &가 아닌 and를 사용해야된다.
3. 마지막에 answer = 0으로 되어있어서 어떤값을 담았더라도 마지막에 0으로 초기화가 된다.
