# 두 수의 연산값 합치기 - 프로그래머스

## 코드
```python
def solution(a, b):
    x = str(a) + str(b)
    y = 2*a*b
    if int(x) > y:
        answer = int(x)
    elif int(x) == y:
        answer = int(x)
    else:
        answer = y
    return answer
```

앞전 문제와 동일하게 x에는 문자로 변환시킨 후 더한 값을,
y에는 문제에서 요구하는 식을 대입하였다

문제의 조건으로 만약 x의 값과 y의 값이 동일하면 x의 값을 출력하라고 주어졌다.

그래서 조건문에서 `elif`를 사용하여 정수로 변환시킨 x의 값이 y값이랑 동일하면
정수로 변환시킨 x의 값을 `answer`변수에 담았다
