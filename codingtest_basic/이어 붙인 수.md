# 이어 붙인 수 - 프로그래머스

## 문제
```
정수가 담긴 리스트 num_list가 주어집니다. num_list의 홀수만 순서대로 이어 붙인 수와 짝수만 순서대로 이어 붙인 수의 합을 return하도록 solution 함수를 완성해주세요.
```

## 예시
```
입출력 예
num_list	result
[3, 4, 5, 2, 1]	393
[5, 7, 8, 3]	581
입출력 예 설명
입출력 예 #1

홀수만 이어 붙인 수는 351이고 짝수만 이어 붙인 수는 42입니다. 두 수의 합은 393입니다.
```

## 코드
```python
def solution(num_list):
    oddNumber = ''
    evenNumber = ''
    for i in num_list:
        if(i % 2 != 0):
            oddNumber += str(i)
        else:
            evenNumber += str(i)
    answer = int(evenNumber) + int(oddNumber)
    return answer
```

## 설명

1. 홀수와 짝수를 문자형태로 붙인 값을 담을 변수가 필요하기에 문자열 형태의 변수를 각각 생성한다
2. num_list의 크기만큼 반복하면서 해당 값이 홀수인지 짝수인지 판단을 한다
3. 홀수와 짝수가 판별이 된다면 해당 값을 `str`로 형변환을 해서 각각의 변수에 담는다
4. 마지막에 문자열 형태로 저장된 값들을 `int`로 형변환을 해서 값을 더한 후 출력한다

## 틀린 점

### 틀린 코드
```python
def solution(num_list):
    str_list = str(num_list)
    oddNumber = 0
    evenNumber = 0
    for i in range(len(str_list)):
        if(str_list[i] % 2 == 0):
            int(oddNumber) += str(str_list[i])
        else:
            int(evenNumber) += str(str_list[i])
    answer = int(evenNumber) + int(oddNumber)
    return answer
```

### 설명

1. 리스트를 먼저 문자열로 변환 하려고했다.
2. 출력되는 값이 정수이기에 정수형태로 홀/짝수 변수를 생성함
3. 반복문을 통해 홀/짝수 판별을 하고 값을 str로 변환 시킨 후 변수에 담으려고했다

### 틀린 점.

1. 굳이 리스트를 문자열로 변환 시킬 필요가 없다. -> 나중에 값 하나하나에 형변환을 시켜주면 되기 때문
2. 변수를 정수로 선언하지 말아야된다 -> 우리가 만들 수는 정수의 합이 아닌 문자열의 합이기때문에 그 합을 담을 변수는 문자열형이어야 된다.
3. 담을 변수는 str인데 담는 변수의 형은 int형이다. -> 형이 불일치 하기때문에 오류생김.
