# 공배수 - 프로그래머스

## **코드**
```python
def solution(number, n, m):
    if (number % n == 0) & (number % m == 0):
        answer = 1
    else:
        answer = 0
    return answer
```
***



n과 m의 공배수이면 1을, 아니라면 0을 출력하는 문제

조건문으로 처음에 
```python
if (number % n == 0 & number % m == 0):
```
이렇게 작성했었다
이렇게 되면 &는 비트 연산자 이기때문에 우선순위가 달라서 답이 달라진다.
==연산자가 &언산자보다 우선순위가 낮기 때문에 &연산자가 먼저 계산이 된다
```python
그래서
number % n == (0 & number % m) == 0
```
이렇게 계산이 되게된다.
