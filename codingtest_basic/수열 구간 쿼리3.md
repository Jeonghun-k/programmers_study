# 수열 구간 쿼리3

## 문제
```
정수 배열 arr와 2차원 정수 배열 queries이 주어집니다. queries의 원소는 각각 하나의 query를 나타내며, [i, j] 꼴입니다.

각 query마다 순서대로 arr[i]의 값과 arr[j]의 값을 서로 바꿉니다.

위 규칙에 따라 queries를 처리한 이후의 arr를 return 하는 solution 함수를 완성해 주세요.
```

## 코드
```python
def solution(arr, queries):
    for i, j in queries:
        arr[i] , arr[j] = arr[j], arr[i]
    answer = arr
    return answer
```

### 설명

1. 제일처음 문제 이해를 잘 못함 arr[i]와 arr[j]의 값을 서로 바꾼다는게 무슨의미인지를 이해를 못함
2. 클로드한테 물어보니 query = [[1,2][2,3]...]이런식으로 구성되어있을 것이고
3. arr[1]번째에 해당하는 값과 arr[2]번째에 해당하는 값을 서로 교환하라는 의미라고 설명을 받음
4. 그래서 queries에 있는 값을 구조분해 할당으로 뽑아와서 반복문을 순회하면서 값을 변경하도록 코드를 짬
