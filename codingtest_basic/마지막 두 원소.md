# 마지막 두 원소 - 프로그래머스

## 문제
```
정수 리스트 num_list가 주어질 때,
마지막 원소가 그전 원소보다 크면 마지막 원소에서 그전 원소를 뺀 값을 마지막 원소가 그전 원소보다 크지 않다면
마지막 원소를 두 배한 값을 추가하여 return하도록 solution 함수를 완성해주세요.
```

## 코드
```python
def solution(num_list):
    answer = num_list
    if num_list[-1] > num_list[-2]:
        num_list.append(num_list[-1]-num_list[-2])
    else:
        num_list.append(num_list[-1]*2)
    
    return answer
```

### 설명

1. answe를 입력받는 리스트로 설정한다
2. 입력받은 리스트의 마지막 원소와 그 앞의 원소를 비교했을때
3. 맨 마지막게 크다면 두 값을 뺀값을 리스트 맨 마지막에 추가를 한다
4. 위에꼐 아니라면 맨 마지막 원소를 두배 곱한 값을 마지막 원소로 넣는다.
