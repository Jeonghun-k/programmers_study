# 홀짝에 따른 다른 값 반환 - 프로그래머스
*문제*
```
양의 정수 n이 매개변수로 주어질 때, n이 홀수라면 n 이하의 홀수인 모든 양의 정수의 합을 return 하고
n이 짝수라면 n 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.
```
***
*코드*
```java
class Solution {
    public int solution(int n) {
        int answer = 0;
        if (n%2 == 0){
            for(int i = 0; i <= n; i++){
                if(i%2 == 0){
                    answer += i*i;
                }
            }
        }
        else{
            for(int i = 1; i <= n; i++){
                if(i%2 != 0){
                    answer += i;
                }
            }
        }
        return answer;
    }
}
```
***
*풀이*

이번 문제는 파이썬으로 풀려다가 if문과 for문이 많아 복잡한것 같아서 java로 문제를 풀었다  

정수형으로 answer를 선언ㄴ해둔다
만약 입력받은 값의 나머지가 0이라면
i가 0부터 n까지 1씩 증가하도록 반복문을 이용하여
`i%2 == 0`일 경우 answer에 i제곱을 더하게한다

홀수일때도 동일하게 `n%2 != 0`이면서, 
`i%2 != 0`일 경우 answer에 i를 더하게 한다
