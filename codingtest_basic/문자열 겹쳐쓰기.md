# 문자열 겹쳐쓰기 

`내가 제출한 답`
```python
def solution(my_string, overwrite_string, s):
    L1 = list(my_string)
    L2 = list(overwrite_string)
    j = 0
    for i in range(s, s+len(L2)):
        L1[i] = L2[j]
        j+=1
    answer = ''.join(L1)
    return answer
```
각 문자열을 리스트화 시켜 변수에 담아둔다
j는 overwrite문자열의 몇번째 글자를 쓸지를 추적하는 역할

s번째부터 (s+덮어쓰고싶은 문자 길이) 만큼 반복
L1의 i번째를 L2배열의 0번째 값으로 변경
이걸 L2가 끝날 때 까지 반복하기

이후 ''.join(L1)을 해서 문자열을 다시 합친다.

그런데 프로그래머스가 의도한 답은 슬라이싱 같음
