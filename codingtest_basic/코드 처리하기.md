# 코드처리하기 - 프로그래머스

## 문제
```
문자열 code가 주어집니다.
code를 앞에서부터 읽으면서 만약 문자가 "1"이면 mode를 바꿉니다. mode에 따라 code를 읽어가면서 문자열 ret을 만들어냅니다.

mode는 0과 1이 있으며, idx를 0 부터 code의 길이 - 1 까지 1씩 키워나가면서 code[idx]의 값에 따라 다음과 같이 행동합니다.

mode가 0일 때
code[idx]가 "1"이 아니면 idx가 짝수일 때만 ret의 맨 뒤에 code[idx]를 추가합니다.
code[idx]가 "1"이면 mode를 0에서 1로 바꿉니다.
mode가 1일 때
code[idx]가 "1"이 아니면 idx가 홀수일 때만 ret의 맨 뒤에 code[idx]를 추가합니다.
code[idx]가 "1"이면 mode를 1에서 0으로 바꿉니다.
문자열 code를 통해 만들어진 문자열 ret를 return 하는 solution 함수를 완성해 주세요.

단, 시작할 때 mode는 0이며, return 하려는 ret가 만약 빈 문자열이라면 대신 "EMPTY"를 return 합니다.
```

## 코드
```python
def solution(code):
    
    ret = ""
    mode = 0
    
    for idx in range(len(code)):
        if mode == 0:
            if code[idx] != '1':
                if idx % 2 == 0:
                    ret += (code[idx])
            else:
                mode = 1
        else:
            if code[idx] != '1':
                if idx % 2 != 0:
                    ret += (code[idx])
            else:
                mode = 0
                
    if ret == "":
        ret = "EMPTY"

    return ret
```
---
## 설명

문제에서 `ret`을 출력하라 했으니 문자열 `ret`변수를 생성한다.  
`mode`에 따라 `code`를 읽어 `ret`에 입력하는 것이니 `mode`의 초깃값인 `0`으로 설정하여 변수를 생성한다.

이후 반복문으로 `idx`를 `code`의 길이만큼 반복한다.  
`mode`의 값에 따라 `code[idx]`의 값이 `1`이 아니고, `idx % 2`가 `0`이라면 `ret`에 `code[idx]`값을 추가한다.
`else`문은 `mode`가 `1`인 경우이다.

맨 마지막에는 `ret`이 비어있다면 `EMPTY`를 출력하도록 하였다.

제일 처음에는 1을 문자가 아닌 정수 1로 반복문을 짜서 테스트했는데 오류가 나왔고
다시 문자 1로 수정을 했다.
