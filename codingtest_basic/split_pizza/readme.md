# 피자 나눠 먹기
1. 피자 한 판은 7조각이다
2. 나눠먹을 사람의 수가 주어질 때, 모든 사람이 한 조각 이상을 먹기 위한 최소한의 피자수를 구하라
# 알고리즘
1. 전체 피자 수를 넣을 변수를 생성한다
2. 만약 인원수를 피자조각 수(7조각)으로 나눈 나머지가 0이라면 (인원수 / 7)이 최소한의 피자 수가 된다
3. (인원수 / 7)이 0이 아니라면 (인원수 / 7)에 +1 을 하면 최솧나의 피자 수를 알 수 있다

# 오답노트
1. else문에서 (n/7) + 7을 해서 마지막 +7이 7조각 추가가 된다라는 의미로 넣었다.
2. 하지만 7조각 추가가 아닌 1판 단위로 추가를 했어야 했기에 답은 (n / 7) + 1이 되어야 한다.
